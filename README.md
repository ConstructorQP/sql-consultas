# Consultas SQL

Colección de consultas SQL de la asignatura *Gestión de Bases de Datos* (ASIR), desde el `SELECT` básico hasta `JOIN` de varias tablas y subconsultas.

## Contenido

| Tema | Archivos |
|---|---|
| Consultas básicas | `SELECTFROMWHERE`, `SELECT TOP n y SELECT DISTINCT`, `NOMBRES CUALIFICADOS DISTINTIVOS` |
| Filtros | `FILTRAR`, `AND, OR, NOT`, `LIKE, BETWEEN, IN`, `NULL` |
| Agregación | `COUNT Y AVG`, `WHERE,GROUPBY,HAVING` |
| Combinación de tablas | `PRODUCTO CARTESIANO`, `JOIN`, `JOIN VARIAS TABLAS` |
| Conjuntos | `UNION, UNION ALL`, `UNION EN USO` |
| Subconsultas | `Subconsultas/` → `IN`, `ALL`, `EXISTS` y subconsultas generales |

## Tecnologías

MySQL / MariaDB · SQL (DQL)

## Cómo usarlo

Los scripts trabajan sobre el esquema `ejemplo`. El archivo `JOIN.sql` incluye la creación de las tablas `departamento` y `empleado`. Ábrelos en MySQL Workbench o DBeaver y ejecútalos en orden.

## Relacionado

El diseño de las bases de datos (tablas, claves y restricciones) está en [sql-diseno-bases-datos](https://github.com/ConstructorQP/sql-diseno-bases-datos).
